# 燃烧试验装备市场当前核心汇总（2026-09-13）

> 本汇总按当前最终口径整理：只统计火灾燃烧、材料燃烧、新能源热失控/火烧/燃爆、大尺度实体火灾、航空/船舶防火以及材料烧蚀/热防护。推进燃烧、高焓风洞、高超声速流动机理、航空发动机燃烧室、工业燃烧器、普通消防探测报警和单纯灭火效能平台均不计入核心市场。

## 一、当前已形成的资料体系

仓库目前已经形成四层数据：

1. `data/tenders_2024_2026.md`：2024—2026年公开采购主表；
2. `data/enterprise_procurement.md` 及补充表：企业侧采购、测试服务和实验室能力建设；
3. `scans/`：7轮专项扫描和3轮小时扫描，包含新增项目、状态补全、价格锚点与边界判断；
4. `data/auto_candidates.*`：GitHub Actions多源自动发现候选库，候选必须再人工核验后才进入正式统计。

当前公开样本已足以支撑产品线、价格带和重点增长方向判断，但尚不足以严谨给出“全国年度总市场规模”这一单一数字。后续全国TAM需要继续补历史项目、企业自筹项目和未公开金额项目，并完成去重和金额拆包。

## 四、检测服务价格已经出现可用锚点

新能源方向已有公开委外测试价格：绝热热失控约1万—3.5万元/项，模组热失控约4万元/项，产气燃烧速率约2万元/项，爆炸极限约2.5万元/项；另有气瓶火烧试验公开限价约2.5万元/次。说明检测公司可以形成“标准材料燃烧+新能源热失控/燃爆+大尺度火灾+烧蚀评价”的组合收费体系，而不只是依赖传统CMA小项目。

## 五、对两家公司的直接含义

### 装备公司

建议形成六级产品矩阵：

1. 氧指数、UL94、烟密度等标准基础设备；
2. 锥形量热、FTIR烟毒、SBI、电缆热释放等中高端标准系统；
3. 耐火试验炉和房间角/家具量热等中尺度成套装备；
4. 电池热失控、外部火烧、燃爆和储能火灾系统；
5. MW级量热、车辆/建筑/隧道等大尺度真实火灾平台；
6. 氧乙炔/火焰烧蚀、复合材料烧蚀和热防护评价装备。

其中1—2级适合做标准化目录和稳定现金流，3—6级是利润、技术壁垒和行业影响力的主要来源。

### 检测公司

最值得形成差异化收费能力的不是普通UL94/氧指数，而是：

- 高端热释放+烟毒联用；
- 电池单体—模组—PACK—簇级热失控/火烧/燃爆；
- 车辆、储能、建筑、隧道等实体火灾；
- 航空舱内/货舱/部件防火；
- 氧乙炔/氧丙烷烧蚀及耐烧蚀复合材料评价。

## 六、目前还不能下的结论

1. 不能直接把综合采购包金额全部计为燃烧市场；必须拆分燃烧相关子项。
2. 不能把推进燃烧、高焓风洞、发动机燃烧室等项目计入本项目核心市场。
3. 当前公开样本可以证明存在“从万元级标准仪器到千万元级成套能力”的多层次市场，但还不足以给出一个经过审计的全国年度总市场规模。
4. 下一步市场规模测算应采用“客户数量×典型配置×设备更新周期+新建实验室+检测服务量”的自下而上模型，而不是简单把公开招标金额相加。
