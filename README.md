# Combustion Equipment Tender Market

中国燃烧试验装备、火灾安全试验系统及相关实验室建设公开招投标样本库。

## 研究目的

本仓库用于持续收集和核验国内公开的燃烧试验装备、火灾安全检测装备及成套实验室建设项目，重点观察：

- 传统标准燃烧仪器的价格与更新需求；
- 新能源汽车与储能热失控、外部火烧、燃爆测试系统；
- 航空/低空防火、货舱火灾和发动机燃烧试验能力；
- 大尺度实体火灾、热释放率及量热系统；
- 氢燃烧、SAF、PIV/PLIF等先进燃烧科学装备；
- 由单台仪器向“试验能力成套交付”的市场迁移。

## 数据口径

本仓库是**公开项目样本库，不等同于全国全量招投标数据库**。项目按来源可靠性分级：

- **A**：中国政府采购网、中央/地方政府采购网、采购单位官网等一手公开来源；
- **B**：公共资源交易平台、学校/科研机构招投标中心、央企电子采购平台等一手或准一手来源；
- **C**：招标聚合网站、仪器行业网站等二手公开来源，仅作为补充线索，后续优先回溯一手公告。

对于包含大量非燃烧设备的综合采购包，项目总金额**不得直接计为燃烧装备市场金额**，会在备注中单独标识。

## 初步结论

目前样本显示，国内市场正在从数万元级标准燃烧仪器，逐步扩展到百万元级专业系统、千万元级成套实验室及亿元级重大试验能力建设。增长最明显的方向包括新能源电池/储能安全、航空与低空防火、大尺度实体火灾、氢能及先进燃烧诊断。
